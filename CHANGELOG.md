# Changelog

## v1.0.0 (2026-10-03)

First public release.

- Pick any terror zone from the full list; favourite zones are pinned to the top.
- Shows the selected zone's last session in your local time, or its next session if the schedule has no earlier one.
- Set the Windows clock to that session, or revert to the real time from `time.windows.com`.
- Optionally restore the real time automatically when the app closes.
- Back up the D2R save folder to a dated zip in `Saved Games\Diablo II Resurrected Backups`.
- Detects a clock left shifted by an earlier session and shows times against the real time.
- Uses the last downloaded schedule when offline.
- Remembers the selected zone, favourites and auto-restore setting between runs.
- Goblin-and-clock artwork with a pixel-art frame and icon.
